# 100 Go Mistakes

Estudo do livro *100 Go Mistakes and How to Avoid Them* (Teiva Harsanyi).
Cada mistake vira uma pasta com um `main.go` executável que mostra o erro e a correção.

## Como rodar

```sh
go run ./001-unintended-variable-shadowing
```
